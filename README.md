# blog.jglass.me

My personal blog site, generated by [Zola](https://getzola.org), styled using the [Shuttle](https://github.com/Jordan-Glass/shuttle) theme, and deployed using [zola-deploy-action](https://github.com/shalzz/zola-deploy-action/). Shuttle is a fork of [Apollo](https://github.com/not-matthias/apollo). A link to the site is included in the repository About panel.
